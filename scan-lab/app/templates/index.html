3D Scan Viewer Demo

scan-lab is a modular Flask demo project for browser-based 3D scan visualization. It is intentionally structured so selected modules can later be transferred into larger projects.

  • Flask backend using the application factory pattern
  • Prepared service layer for business logic
  • Interactive viewer with three.js-based model inspection tools
  • Separate folders for templates, static assets, and data

Supported Import Formats

The viewer currently supports local uploads and sample previews for STL, OBJ, PLY, 3MF, GLB, and glTF.

  • STL: common triangle mesh format for CAD and 3D printing workflows
  • OBJ: classic exchange format for polygon meshes
  • PLY: scan-oriented mesh format, often used with measured geometry and optional vertex colors
  • 3MF: zipped manufacturing format with mesh, material, and production metadata support
  • GLB: binary glTF container with geometry, materials, and textures bundled in one file
  • glTF: JSON-based scene format; local uploads work best when buffers and textures are embedded

GLB and glTF belong to the same format family. GLB is usually the more robust single-file variant, while glTF may reference additional .bin or texture files.
